02 · The index

Index once.

Six stages on your machine, cached and signed. The app, the MCP server and the CLI all read the same index.

Show the receipt
01Ingest / clonea folder or a git URL
02ParsePython: full AST (deepest) · JS/TS: built-in parser · Go, Java, Rust, C#, Ruby, PHP, C, C++, Kotlin, Swift, Scala via the treesitter extra
03Build code graph2 node types · 5 edge types
04Chunksearchable chunks
05Build retrieversBM25 always · on-device embeddings optional · fused with Reciprocal Rank Fusion · expanded through the call graph
06CacheHMAC-signed per install

Stdlib-first: Python's own ast, a hand-rolled graph, BM25 from scratch. A fixed sample repo pins its exact invariants in tests. The graph is computed, not predicted.

SKILL.md rules: before editing any function → blast_radius · before changing a signature → callers_of · before merging → cycles. Index builds lazily on the first call; graph tools need no LLM and no embeddings.

$uvx --from "legend-lens[mcp]" legend mcp --repo .

05 · In the repo and in CI

Gate your pull requests.

legend check fails a PR on a new import cycle or a removed public symbol. legend context writes AGENTS.md from the graph.
