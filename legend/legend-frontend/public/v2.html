Open source · MIT · Python 3.10+

Your codebase, as a graph.
Not a pile of text matches.

Legend indexes a repo once, on your machine, into files, symbols and resolved call and import edges. Browse it in a local app, hand the same graph to your coding agent over MCP, gate pull requests on it in CI.

01 · Why not grep?

grep finds text. Legend finds edges.

Ask grep who calls post_entry and you get every line that contains the word. Legend resolves each call by its receiver — bare, self, typed, attr — and draws an edge only when it is sure. Two node types, five edge types, no guesses.

02 · The index

Index once. Everything reads from it.

Point Legend at a folder or a git URL. Six stages later there is one in-memory index — symbols, the graph, searchable chunks and their retrievers — cached and HMAC-signed per install, shared by the app, the MCP server and the CLI.

The engine is stdlib-first — Python's own ast, a hand-rolled graph, BM25 written from scratch — and a fixed sample repo pins its exact invariants in tests. That is why "no model needed" holds: the graph is computed, not predicted.

03 · The local web app

Eight views. One index. Seven of them need no model.

Open the app on localhost and browse structure, files, graphs and metrics. Only Ask needs an LLM — it streams an answer and cites file, lines, symbol and how each source was found. A model is optional elsewhere: file summaries, function explanations and Timeline's "Explain this change" use one only if you configure it.

04 · For coding agents · MCP

One deterministic call instead of ~15 greps.

The MCP server exposes 13 read-only tools over the same graph — the same HMAC-signed index the app reads. It builds lazily on the first call; graph tools need no LLM and no embeddings. A SKILL.md tells the agent when to reach for which tool.

05 · In the repo and in CI

Context that cannot drift. A gate that fails on structure.

legend context derives AGENTS.md from the graph — entry points, real import edges, routes, models, cautions — so you regenerate it each commit instead of maintaining it. legend check --base main runs on a pull request and fails it on a new import cycle or a removed public symbol; a complexity spike of 5 or more is a warning, and --strict makes it blocking too.

06 · Local-first

Everything above happened on one machine.

Legend binds to loopback, keeps no account and sends no telemetry. The only outbound traffic is the git clone you asked for and, if you enable one, calls to the model you configured.

Run it on a repo you have never seen.

Zero install with uv. Or pipx, or pip. Python 3.10+. Extras when you want them: semantic · llm · treesitter · export · mcp · all.
